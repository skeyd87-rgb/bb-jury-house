# 0.5.12

Export the season.

- **Export season** (Menu, and on the final results screen) produces one text file with the whole game: week by week, each comp with its scores, every event, every vote, every conversation — 1-on-1, group and Diary Room — promises and how they ended, alliances, what each houseguest held against whom, what you overheard, and the finale's questions, answers and votes. The raw save is attached at the end so anything in the readable part can be checked exactly.
- **Each houseguest line is marked [AI] or [offline writer]**, so a reply that reads wrong can be traced to where it came from.
- On a phone the button opens the share sheet (save to Files, send it to yourself); on a computer it downloads the file. **Copy all text** is there on both.
- **The title screen offers the same export** for a season still saved on the device, or, after you start a new one, for the last season you finished.
- The game now keeps the complete conversation transcript in the save. Before, only the last 24 lines with each houseguest were kept, because that is all the AI is shown.

A season played before this version can still be exported if it is still saved on that device, but it only has those last 24 lines per houseguest and no finale questions or answers.

Nothing is uploaded. The file goes wherever you send it.

Single-player only: an online game lives on the room server, and exporting it is not built.

Validation: a sample season through the record builder, read by eye, with the attached save parsing back to the same game; in the browser at phone size, a conversation, Menu → Export season, the export card, Copy all text (13 KB, containing the conversation and the save), and the title-screen export of a saved season. The share sheet itself cannot be exercised in the test browser, so the phone path is unverified. 28 grounding (the Diary Room test now permits diary lines in the transcript and nothing else), betrayal and consistency regressions; 60 simulated seasons; production build.
